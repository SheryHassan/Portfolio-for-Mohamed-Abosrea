# My Front-End Project 🚀

This project was built entirely using **HTML, CSS, and SASS**.  
It showcases some key techniques I learned during my **Front-End Development journey**.

---

## Technologies Used 🛠️

- **HTML5** – to structure the webpage  
- **CSS3** – for styling and layout  
- **Flexbox** – for responsive row and column arrangements  
- **CSS Grid** – to organize the page layout  
- **SASS (SCSS)** – for cleaner, more maintainable code using **Variables, Nesting, and Mixins**

---

## Project Features ✨

- Fully **Responsive Design** for all screen sizes  
- Layout organized with **Flexbox and Grid**  
- Code divided into **Components** using SASS  
- Supports **Dark Theme**  
- Includes **Burger Menu** for easy navigation  
- Uses **Google Fonts** for typography  
- Built **without any JavaScript** 🚀
